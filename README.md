# IrodoriStudio

Windows 10/11 x64向けの、Irodori-TTS連携ローカル音声生成アプリです。

## 配布と初回セットアップ

`IrodoriStudio.exe` と同じフォルダをそのままコピーして使うポータブル形式です。管理者権限やレジストリ登録は使いません。

初回準備前は `IrodoriStudio.exe` だけを置いて起動できます。必要なruntime・Python・音声生成プログラム・依存部品・モデル・FFmpegは、exeの隣へ自動取得します。準備済みの環境を保存場所ごと移動する場合は、サーバーを停止してから `IrodoriStudio.exe` と生成されたフォルダ全体を移動してください。起動時にexeの場所を基準に保存先を組み直し、設定・ボイス・生成履歴の絶対パスも新しい場所へ自動調整します。

初回起動時に、Windows・CPU・GPU/CUDA・保存権限と各コンポーネントの有無を自動確認します。利用条件を確認した後の「不足している項目を準備」画面から、不足項目だけを準備できます。「不足項目をまとめて準備」を選ぶと、実行環境・Python・音声生成プログラム・必要な部品・モデル・音声変換機能を1項目ずつ順番に処理し、完了するたびに状態を更新します。後から「設定 > 環境確認」でも再実行できます。

環境の準備を後回しにしても、必要な項目が残っている間は次回起動時に確認画面を表示します。現在の作業を続ける場合は「後で開く」を選択できます。

### 必要な空き容量と時間の目安

| 項目 | GPU（CUDA）を使う場合 | CPUのみの場合 |
| --- | --- | --- |
| 必要な部品（Python・PyTorchなど） | 約6GB | 約2GB |
| 音声モデル（Original） | 約3GB | 約3GB |
| 音声モデル（Quantized） | 約1GB | 約1GB |
| その他（実行環境・FFmpegなど） | 約0.5GB | 約0.5GB |

合計で **GPU利用時は約10GB、CPUのみなら約6GB** の空き容量が必要です。回線速度によっては初回準備に30分以上かかります。準備中は画面に進み具合を表示します。

- モデルのダウンロードが途中で止まっても、もう一度実行すると続きから再開します。取得したファイルはSHA-256で確認し、壊れていれば自動で取り直します。
- NVIDIA GPUは、RTX 20系以降（Compute Capability 7.5以上）かつドライバ528.33以上の場合にGPU版を準備します。準備後にGPUで実際に計算できるかを確認し、失敗した場合は自動でCPU版に切り替えます。

### 生成した音声の保存期間

生成直後の音声は一時ファイルとして `data/temp/` に保存し、**3日たつと起動時に自動で削除**します。残したい音声はお気に入りに追加してください（`data/favorites/` に保存され、自動削除されません）。

### Hugging Faceからのモデル追加

設定 > モデル の検索では、このアプリで読み込める形式のモデルだけを表示します（Apple向けMLX版、GGUF版、ONNX版は除外します）。導入前にモデルファイルの先頭部分だけを取得して中身を確認し、同梱のIrodori-TTSでは読み込めない派生モデルはダウンロードせずに理由を表示します。

モデルは Original / Quantized を選択し、設定したrevisionを `models/` へ保存します。大容量モデルの取得にはネットワーク接続と十分な空き容量が必要です。取得後の音声生成・絵文字解析はローカルで行い、テキストと音声を外部APIへ送信しません。

## 開発ビルド

```powershell
npm install
npm run tauri build -- --no-bundle
.\build-portable.ps1
```

出力される `IrodoriStudio.exe` は単体配布して初回セットアップを実行できます。準備済みの状態で配布する場合は、`runtime/`、`irodori/`、`server/`、`models/`、`data/` と同じ階層のフォルダ全体を配布してください。Python/PyTorchとモデルを完全同梱した軽量exeではないため、未準備のPCでは初回セットアップのダウンロードが必要です。配布先にGitのインストールは必要ありません。

## GitHubでソースとインストーラーを配布

GitHubでは、ソースコードをリポジトリへ登録し、Windows用インストーラーをReleaseの添付ファイルとして配布します。インストーラーへPython・PyTorch・音声モデルを同梱しないため、ファイルサイズを抑えたまま、初回起動時に不足している項目だけをアプリのフォルダへ取得できます。

ローカルでNSISインストーラーを作成する場合は、次を実行します。

```powershell
npm ci
npm run build:installer
```

インストーラーはユーザー単位でインストールされます。管理者権限を使わずに初回セットアップが実行でき、インストール後も書き込み可能なフォルダへアプリ全体を移動できます。`Program Files` など書き込みが制限される場所へ移動した場合は、初回セットアップで管理者権限が必要になることがあります。生成されたファイルは `src-tauri/target/release/bundle/nsis/` に出力されます。

GitHub Actionsは `v0.1.0` のようなタグをpushするとWindowsインストーラーをビルドし、GitHub Releaseへ自動添付します。Actions画面から手動実行した場合は、インストーラーをArtifactとして取得できます。

インストーラーには実行環境とモデルを含めないため、利用者の初回起動時にはネットワーク接続と、モデルを保存する空き容量が必要です。

## Irodori-TTSについて

開発時・配布時ともに、既定の参照先は `IrodoriStudio.exe` と同じフォルダ内です。初回セットアップから公式GitHubのソースをZIPで `irodori/` と `server/` へ取得し、Git依存の部品はアプリ内でZIPまたはPythonパッケージとして準備します。設定画面で利用者が別のフォルダを指定した場合に限り、その指定先を使用します。

`licenses/` には開発時に確認したIrodori-TTS / Irodori-TTS-ServerのLICENSE本文を同梱しています。モデル・Python依存パッケージを追加取得する場合は、取得したrevisionの利用条件も確認して配布してください。著作権表示を推測して追加しないでください。
