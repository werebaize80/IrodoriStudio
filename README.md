# IrodoriStudio

Windows 10/11 x64向けの、[Irodori-TTS](https://github.com/Aratako/Irodori-TTS)を使ったローカル音声生成アプリです。
文章から音声を作り、ボイス（声）の登録やお気に入りでの音声管理ができます。音声の生成はすべてこのPCの中で行います。

一応virustotalの結果（ウイルスチェッカーみたいなやつ）

ポータブル版（zip）

[https://www.virustotal.com/gui/file/6c578d79ebb400e7f640ec5b92d7cf6d11b49f62bb7fc6adf3b9ced719322547?nocache=1](https://www.virustotal.com/gui/file/9e30b575e6b58264e5a3e45c2033cb1b2350a1cfca7cc1db9e2ebf09a38aeb7d?nocache=1)

## 安心して使っていただくために

### 入力した文章や音声は外部に送信しません

音声の生成は、アプリが自分のPCの中で起動する音声生成サーバーで行います。入力した文章、登録したボイス、
参照音声、生成した音声を、インターネット上のサービスへ送る処理はありません。
ソースコードはすべてこのリポジトリで公開しています。

アプリがインターネットに接続するのは、次の場合だけです。

| いつ | 接続先 | 内容 |
| --- | --- | --- |
| 初回セットアップ | GitHub、Hugging Face、gyan.dev、PyPI、PyTorch公式（download.pytorch.org） | 実行に必要なソフトウェアとモデルのダウンロード |
| 設定 > モデル で検索・追加したとき | Hugging Face | モデルの検索と、選んだモデルのダウンロード |
| 音声生成サーバーの起動時 | Hugging Face | 音声コーデック（約480MB）の初回ダウンロードと、2回目以降の更新確認 |

### ダウンロードするものと、その確認方法

アプリ本体には実行環境やモデルを含めず、初回セットアップで各配布元から直接ダウンロードします。
ダウンロードしたファイルは、次の方法で改ざんや破損がないかを確認してから使います。

| ダウンロードするもの | 確認方法 |
| --- | --- |
| uv（Pythonの実行管理ツール） | バージョンを固定し、公式が公開するSHA-256と照合 |
| FFmpeg（音声変換） | バージョンを固定し、SHA-256と照合 |
| Python依存パッケージ（PyTorchなど） | アプリに同梱した `uv.lock` のバージョンとハッシュで照合（どのPCでも同じバージョン） |
| Irodori-TTS / Server などのソース | コミットを固定して取得 |
| 音声モデル | Hugging Faceが公開するSHA-256でファイルごとに照合 |

ハッシュが一致しない場合は使用せずに中止します。各ソフトウェアのバージョン、取得元、ライセンスは
[THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt) に記載しています。

### フォルダを削除するだけでアンインストールできます（ポータブル版）

ポータブル版は、ダウンロードしたものも含めて、すべて `IrodoriStudio.exe` と同じフォルダの中に保存します。
管理者権限、レジストリ、`AppData` などのフォルダ外の場所は使いません。
アンインストールするときは、サーバーを停止してアプリを閉じ、フォルダごと削除してください。

インストーラー版は、Windowsにアンインストール情報とスタートメニューのショートカットを登録します。
Windowsの「設定 > アプリ」からアンインストールし、インストール先のフォルダが残っていれば削除してください。

### コード署名について

現在、`IrodoriStudio.exe` にはコード署名をしていません。そのため、初めて起動するときにWindowsの
「WindowsによってPCが保護されました」という画面が表示されることがあります。
「詳細情報」から「実行」を選ぶと起動できます。

### 音声クローンについて

参照音声を使うと、その人に似た声を生成できます。本人の明示的な同意や必要な権利を得ていない声のクローン・
なりすまし、詐欺や虚偽情報の作成、本人の発言だと誤認させる目的での利用は禁止しています。
詳しくは [VOICE_CLONING_NOTICE.txt](VOICE_CLONING_NOTICE.txt) をご覧ください。

## 使い方

1. `IrodoriStudio.exe` を、書き込みできるフォルダ（例: `D:\Tools\IrodoriStudio\`）に置いて起動します
2. 初回セットアップで環境と利用条件を確認し、「不足項目をまとめて準備」を選びます
3. 準備が終わったら、画面左下の「サーバーを起動」を選びます
4. 「音声生成」で台本に文章を入力し、「音声を生成」を選びます

台本は**改行ごとに1区間**として生成します。声が途中で崩れる・早口になる・語句が抜けるときは、
長い文を改行で短い区間に分けてみてください。

### 必要な空き容量と時間の目安

| 項目 | GPU（CUDA）を使う場合 | CPUのみの場合 |
| --- | --- | --- |
| 必要な部品（Python・PyTorchなど） | 約6GB | 約2GB |
| 音声モデル（Original） | 約3GB | 約3GB |
| 音声モデル（Quantized） | 約1GB | 約1GB |
| その他（実行環境・FFmpeg・音声コーデックなど） | 約1GB | 約1GB |

合計で **GPU利用時は約11GB、CPUのみなら約7GB** の空き容量が必要です。回線速度によっては初回準備に
30分以上かかります。準備中は画面に進み具合を表示します。

- モデルのダウンロードが途中で止まっても、もう一度実行すると続きから再開します。
- NVIDIA GPUは、RTX 20系以降（Compute Capability 7.5以上）かつドライバ528.33以上の場合にGPU版を準備します。
  準備後にGPUで実際に計算できるかを確認し、失敗した場合は自動でCPU版に切り替えます。
- 準備を後回しにしても、必要な項目が残っている間は次回起動時に確認画面を表示します。
  後から「設定 > 環境確認」でも実行できます。

### 生成した音声の保存期間

生成直後の音声は一時ファイルとして `data/temp/` に保存し、**3日たつと起動時に自動で削除**します。
残したい音声はお気に入りに追加してください（`data/favorites/` に保存され、自動削除されません）。

### Hugging Faceからのモデル追加

設定 > モデル の検索では、このアプリで読み込める形式のモデルだけを表示します（Apple向けMLX版、GGUF版、
ONNX版は除外します）。導入前にモデルファイルの先頭部分だけを取得して中身を確認し、同梱のIrodori-TTSでは
読み込めない派生モデルはダウンロードせずに理由を表示します。追加したモデルは、そのモデルの配布ページに
記載された利用条件に従ってください。

### フォルダの移動

準備済みのフォルダを移動する場合は、サーバーを停止してアプリを閉じてから、`IrodoriStudio.exe` と
生成されたフォルダ全体を移動してください。次の起動時に、新しい場所に合わせて設定・ボイス・生成履歴の
保存先を自動で調整します。

## 開発者向け

### ビルド

```powershell
npm install
npm run tauri build -- --no-bundle
.\build-portable.ps1
```

`IrodoriStudio.exe` だけを配布すれば、利用者のPCで初回セットアップが実行されます。

準備済みのフォルダ（`runtime/` などを含む状態）をそのまま配布すると、FFmpeg（GPL v3）などの第三者
ソフトウェアを再配布することになります。その場合は [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)
の「準備済みのフォルダを再配布する場合」を確認してください。

### インストーラー

```powershell
npm ci
npm run build:installer
```

インストーラーはユーザー単位でインストールされ、管理者権限を使いません。`Program Files` など書き込みが
制限される場所へ移動した場合は、初回セットアップで管理者権限が必要になることがあります。
生成されたファイルは `src-tauri/target/release/bundle/nsis/` に出力されます。

GitHub Actionsは `v0.1.0` のようなタグをpushするとWindowsインストーラーをビルドし、GitHub Releaseへ
自動添付します。Actions画面から手動実行した場合は、インストーラーをArtifactとして取得できます。

### Irodori-TTSについて

初回セットアップで公式GitHubのソースを固定したコミットでZIP取得し、`irodori/` と `server/` に展開します。
Git依存の部品はアプリ内でZIPまたはPythonパッケージとして準備するため、利用者のPCにGitは必要ありません。
